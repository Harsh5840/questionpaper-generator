### 3. Use the exact allowed values for these fields
These columns only accept a fixed set of values. Anything else gets rejected.

- **`question_type`** → `section`, `mcq`, `assertion_reason`, `short_answer`,
  `extended_answer`, `fill_blanks`, `true_false`, `matching`, `other`
  - you currently emit `fill_blank` → must be `fill_blanks`
  - you currently emit `case_study` → there's no such value, use `other`
- **`source_type`** → never blank.
  - question pulled from the book corpus → `ncert`
  - question generated by Gemini → `ai`
- **`input_mode`** (on the assignment) → `ncert` or `manual` (not `image`)
- **`status`** → `draft`, `published`, `grading`, or `completed`

**Why:** these are strict enums. A typo or an extra value makes the whole save fail.

### 6. Saving — update rows, don't delete and recreate

rows. Change it to update the existing rows in place, matching them by
`source_question_key`. Only insert genuinely new questions, only delete removed ones.
Each question must keep the same id across edits.

**Why:** other things (student answers, marks) point at a question by its id. If you
delete and recreate, those ids change and everything attached to them is orphaned.
